## 1. 概要

### 1-1. このリポジトリの目的

Amazon SQS(Simple Queue Service)の基本的な使い方を学ぶためのマニュアルです。次の内容をまとめています。

- AWS CDK(TypeScript)による SQS キューの構築
- AWS SDK を使ったメッセージの送信・受信・削除のサンプル
- 構築手順や設計判断の記録(`log/` 配下)

### 1-2. 対象読者・前提知識

- AWS の基本操作(IAM、リージョン、プロファイル)を把握している方
- TypeScript / Node.js の基本的な読み書きができる方
- SQS は初めて、または概要だけ知っている方

| 項目 | バージョン・条件 |
| --- | --- |
| Node.js | 20 以上 |
| AWS CDK | v2 |
| AWS アカウント | CDK Bootstrap 済みであること |
